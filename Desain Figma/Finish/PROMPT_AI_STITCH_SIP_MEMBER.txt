=== MASTER DESIGN BRIEF: SIP-Member Parking System ===
Role: You are a Principal UI/UX Designer specializing in operational enterprise dashboards and kiosk interfaces. Design a complete, professional, highly user-friendly web application for "SIP-Member" (Sistem Informasi Parkir Khusus Member Berlangganan) — a membership-based parking management system for a school project. The design must be pixel-perfect, Figma-ready with Auto-Layout logic, and visually impressive for academic presentation.

=== DESIGN SYSTEM FOUNDATION ===

Typography:
- Primary: "Plus Jakarta Sans" (headers, body, UI labels)
- Monospace: "JetBrains Mono" or "SF Mono" (license plates, transaction IDs, timestamps, PIN digits)
- Scale: Display 36/40, H1 28/32, H2 20/24, H3 16/20, Body 14/20, Caption 12/16, Micro 10/14

Color Palette:
- Primary Brand: Indigo (#4F46E5 main, #3730A3 hover, #EEF2FF surface, #E0E7FF border)
- Success/Active: Emerald (#10B981 main, #059669 hover, #ECFDF5 surface)
- Warning/Expiring: Amber (#F59E0B main, #D97706 hover, #FFFBEB surface)
- Danger/Expired: Rose (#EF4444 main, #DC2626 hover, #FEF2F2 surface)
- Neutral: Slate (#0F172A text-primary, #334155 text-secondary, #64748B text-muted, #CBD5E1 border, #F1F5F9 bg-secondary, #F8FAFC bg-primary, #FFFFFF surface)
- Special - Gate LED Display: Pure black (#000000) background with neon-colored monospace text

Spacing & Layout:
- Base unit: 4px grid
- Border radius: 8px (inputs), 12px (cards small), 16px (cards large), 24px (modals, hero sections)
- Shadow: sm (cards), lg (modals/dropdowns), 2xl (floating elements)
- Touch targets: minimum 48px height for all interactive elements (critical for kiosk screens)

Component Style:
- Inputs: Rounded-xl, 1px slate-200 border, subtle inner shadow, 40px height desktop / 48px kiosk
- Buttons: Rounded-xl, bold 13px text, icon-left layout, shadow-sm on primary CTA
- Cards: White bg, 1px slate-200 border, rounded-2xl, subtle shadow-sm
- Tables: Alternating row hover (slate-50), sticky header, compact 13px text
- Badges/Status Pills: Rounded-full, 10px bold uppercase text, tinted background + matching border
- Modals: Rounded-3xl, backdrop-blur overlay, slide-up animation implied
